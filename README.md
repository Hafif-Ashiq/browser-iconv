# Iconv-Lite Browser Version

This repository contains a browser-compatible version of the [iconv-lite](https://github.com/ashtuchkin/iconv-lite) Node.js package. Iconv-lite is a library for converting character encodings in JavaScript.

## Usage in Browser

The browser version of iconv-lite is hosted on [jsDelivr](https://www.jsdelivr.com/), a free CDN for open-source projects. You can include it in your HTML file as follows:

```html
<script src="https://cdn.jsdelivr.net/gh/Hafif-Ashiq/browser-iconv/iconv.min.js"></script>
```

Once included, you can use the library in your browser-based JavaScript code just like you would in Node.js.

## Features
- Lightweight and fast.
- Supports a wide range of character encodings.
- Easy to use in both Node.js and browser environments.

## Installation

If you want to use this package in a Node.js environment, you can install it via npm:

```bash
npm install iconv-lite
```

For browser usage, simply include the script from jsDelivr as shown above.

## Documentation

For detailed usage and API documentation, please refer to the [official iconv-lite documentation](https://github.com/ashtuchkin/iconv-lite#readme).
